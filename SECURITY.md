# Security Policy

BlendViewer is a pre-release desktop application. There is no hosted service or user data collection involved.

## Reporting a Vulnerability

If you discover a security issue (e.g. unsafe file parsing, path traversal via imported model files, etc.), please **do not open a public issue**. Instead:

- Use GitHub's [private vulnerability reporting](https://github.com/Chester-xx/BlendViewer/security/advisories/new) for this repository, or
- Contact the maintainer directly via the profile listed on the repository.

Please include steps to reproduce and, if possible, a minimal `.gltf`/`.glb` file that triggers the issue.

## Supported Versions

This project has not reached a stable 1.0 release. Security fixes will be applied to the latest `main` branch only until versioned releases begin.
